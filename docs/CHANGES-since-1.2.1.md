## 一、新增功能

### 1.1 熄屏按钮

快捷按钮从 3 个增加到 4 个，顺序为 **主题 / 自动 / 设置 / 熄屏**，新增电源图标按钮。

| 环节 | 实现 |
| --- | --- |
| 关闭 | 对选中屏写 DDC/CI `VCP 0xD6`：先 4（软关），200 ms 后读回确认；不生效再试 5（硬关） |
| 兜底 | 两种值都失效时广播 `SC_MONITORPOWER`（系统级关屏，必然生效，代价是所有屏一起关） |
| 记忆 | 熄屏前记录每台屏的当前亮度 |
| 恢复 | 任意键鼠输入后写 `0xD6=1`（部分固件需二次点亮），并回放熄屏前亮度 |

### 1.2 熄屏防误触

原来熄屏后 800 ms 就会恢复——因为「按下熄屏按钮」本身就是一次输入，被判定为「用户动了」。

现在改为：熄屏瞬间记录当前系统输入时间戳作为基线，**3 秒宽限期内持续吸收**所有输入（每 150 ms 刷新基线），3 秒后只有出现**新的**输入才点亮。

### 1.3 设置页扩展与鼠标设置

- 设置页从 400×570 加高到 400×700，切换页面时窗口底部锚点不变
- 新增「鼠标设置」分组：托盘图标滚轮开关、面板内滚轮开关
- 两个开关分别持久化到 `WheelTray` / `WheelPanel`

### 1.4 日间 / 夜间亮度

原「起始亮度 / 结束亮度」改为 **日间亮度 / 夜间亮度**，并与时间同行双列排布：

```
开始时间  08:00  −  +      日间亮度  80%  −  +
结束时间  18:00  −  +      夜间亮度  20%  −  +
```

新增配置 `DayPct` / `NightPct`（默认 80 / 20），时间步进 ±1 小时，亮度步进 ±5%。

### 1.5 HDR 基准亮度标定

托盘菜单新增「标定 HDR 基准亮度」：读取 Windows「SDR 内容亮度」滑条最右端对应的白电平，存入 `WlMax`（本机标定值 ≈3850）。同时新增「校准滚轮图标位置」，记录托盘图标的实际屏幕坐标（`TrayX` / `TrayY`），供滚轮命中判定使用。

### 1.6 面板位置记忆

拖动面板后，进入设置页再返回不再跳回右下角默认位置。实现：拖动结束（`WM_EXITSIZEMOVE`）记录左上角并置 `g_moved`；`PlacePanel()` 优先使用该坐标，仅在新页高越出工作区时向上收回；关闭面板时清空记录。

### 1.7 HDR 遮罩调光

HDR 显示器固件锁死 DDC 亮度寄存器时，新增第二级调光：每屏一个黑色分层窗口，通过 `SetLayeredWindowAttributes` 调节不透明度，与 gamma LUT 叠加使用（详见 2.4）。

### 1.8 HDR 提示行双读数

HDR 激活时，面板提示行同时显示两层亮度：`Windows 白电平 N · lumen 调光 M%`。

前者通过目标通道的 SDR 白电平查询读取（随 3 秒 HDR 轮询刷新），实时镜像系统设置里的「SDR 内容亮度」滑条；后者是 lumen 自己的相对调光。两个数字是不同维度（基准白电平 vs 相对压暗），不是同一控件的两份副本。

之所以分两行显示而不是合并成一个数：实测不存在可写的 SDR 白电平通道（`DisplayConfig` 类型 14–64、两种结构体尺寸、target/source id 全部试过，另做了全量 VCP 扫描），无法通过公开接口与系统滑条统一。双读数是这个问题下唯一诚实的呈现方式。

## 二、行为改进

### 2.1 自动调节改为两段渐变

| | 1.2.1 | 现在 |
| --- | --- | --- |
| 曲线 | 起止时间之间线性插值 25–100% | 两个端点各做 8 分钟渐变 |
| 端点 | 无独立亮度 | 日间 / 夜间可分别设置 |
| 生效时机 | 开关打开后等下一次定时器（最多 60 秒） | 开关打开立即按当前时间计算 |

渐变时间固定 8 分钟（落在 5–10 分钟区间）：到开始时间升到日间亮度，白天保持；到结束时间降到夜间亮度，夜间保持。

### 2.2 托盘滚轮改 Raw Input

Windows 11 不再向托盘图标转发 `WM_MOUSEWHEEL`，原实现依赖 explorer 转发，在新系统上失效。改为 `RegisterRawInputDevices` + `WM_INPUT` 直接接收鼠标滚轮，用光标位置判断是否落在托盘图标邻域。

### 2.3 滚轮跟手

原实现把 160 ms 内的滚动累积后一次性应用，并把结果钳制在 ±2 步——快速滚 5 格只涨 2 步、且要停手才跳数。

现在按 `delta / 120 × 步长` 即时计算并立即更新数值、弹 OSD；写入频率仍由后台写入线程合并，不受影响。高精度滚轮（`delta < 120`）兜底 ±1。

### 2.4 HDR 调光改为 10% 两段式

| 区间 | 通路 |
| --- | --- |
| 10% ~ 100% | 纯 gamma LUT：`scale = (目标 ÷ baseL)^(1/2.2)`，遮罩 alpha = 0 |
| 0% ~ 10% | gamma 锁在 10% 处的基准值，遮罩 alpha 从 0 线性加深到 94（透光 6%） |

两段在 10% 处亮度连续。原实现的分界是 gamma 系数 0.5，与百分比无固定对应关系。

配套三项稳定性改造：

- 原始 LUT 按屏备份（含校色曲线），写入时在备份上乘系数，退出时写回；启动发现中点明显偏暗（上次被强杀）先归一
- 每次写 LUT 后读回比对，连续两次不符判定该环境不可用，自动降级为全区间遮罩
- 写入改在后台写入线程同步执行（异步子线程会造成写入错序），DC 缓存复用，启动预热

### 2.5 熄屏恢复判据

原判据用「最后一次输入时间是否晚于熄屏时刻」；改为比对熄屏瞬间记录的基线时间戳是否发生变化。

## 三、修复

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 熄屏后立刻自己亮回来 | 按钮点击本身被算作新输入，800 ms 宽限一过就触发恢复 | 基线时间戳 + 3 秒吸收窗口（1.2 / 2.5） |
| HDR 下调光不跟手、数值错乱 | gamma 写入在独立线程中异步执行，先后顺序无法保证；DC 反复创建销毁会卡住 | 同步写入 + DC 缓存 + 读回校验降级（2.4） |
| 切设置页/返回时面板跳回右下角 | `PlacePanel()` 每次按默认位置重算 | 拖动后记住左上角（1.6） |
| 任务管理器里找不到进程 | 「名称」列显示的是版本资源的 `FileDescription`，原值是 `lumen brightness control` | 改为 `lumen`，与程序名一致 |
| 设置页时间值折行 | 40 px 宽、13 px 加粗的 `08:00` 被 GDI+ 折成两行 | 降至 12 px，单行显示 |

## 四、工程与工具

新增 5 个回归/诊断工具（均为独立 exe，静态链接，不参与主程序）：

| 工具 | 用途 |
| --- | --- |
| `vcp.cpp` | 读写任意 DDC/CI 寄存器（`0xD6` 电源、`0x10` 亮度），验证固件是否支持 |
| `sdrwl.cpp` | 读写 Windows SDR 白电平，用于确认系统是否允许应用修改 |
| `dimstate.cpp` | 读取当前 gamma LUT 中点值与遮罩 alpha，验证两级调光实际状态 |
| `movepanel.cpp` | 移动面板窗口并模拟拖动结束，验证位置记忆 |
| `resmon.cpp` | 采样进程 CPU / 工作集 / 私有提交 / 句柄 / 线程 / GDI+USER 对象 |

另归档 `perf/` 目录：8 个场景的资源采样 CSV（待机、面板静止、拖动、开合切页两轮、快捷键、熄屏恢复、冷启动）。

## 六、已知边界

1. **HDR 下 gamma LUT 不保证可用。** 本机实测 `SetDeviceGammaRamp` 写入后读回不符，程序会自动降级为全区间遮罩——亮度仍跟手、极暗可到 6% 透光，但 HDR 高光会被一起压暗。
2. **`SET_SDR_WHITE_LEVEL` 被系统拒绝。** 实测返回 87（参数无效），读可写不可。方案一只能走 gamma LUT，不能改系统全局白电平。
3. **熄屏是软关。** `0xD6=4` 让显示器进待机，DDC 通道保留、任意输入可唤醒；想要电源灯全灭只能硬关（`0xD6=5`，部分固件会断 DDC，需按物理电源键）。
4. **自动调节不支持跨午夜。** 结束时间必须晚于开始时间，按小时步进。
5. **熄屏兜底会关全部屏。** `SC_MONITORPOWER` 是系统级广播，无法只关一台。
